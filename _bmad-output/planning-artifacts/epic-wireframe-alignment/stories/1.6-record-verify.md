# Story 1.6 — Verify `record` copy + flow against wireframe A3

- **Status:** Draft
- **Epic:** [EPIC-WF-ALIGN](../epic.md)
- **Depends on:** 1.1
- **Blocks:** —

## User story

As a Chirp user starting a recording, I want the prompts (including a new optional tags prompt), header, waveform, listening spinner, and control hints to read and behave exactly as wireframe A3 specifies, so that the live experience matches the design and users learn the controls from the screen rather than from docs.

## Context

Most of `record` is already built: title + timeframe prompts, live dashboard with scrollable transcript, VAD, pause/resume, stop-and-save. This story is a polish pass to:
1. Add a new optional **tags** prompt (comma-separated) after timeframe.
2. Confirm the header, waveform, spinner, and control hints match A3.
3. Repoint the audio target at the new `notes_root/<slug>/audio.wav` path (story 1.1 handles the plumbing; this story verifies the user-facing surface).

Tags captured here populate `meta.toml`'s `tags` array and drive filtering in `chirp notes --tag` (story 1.3).

## Acceptance criteria

- **AC-1** Prompt order is **title (required)** → **timeframe (optional)** → **tags (optional)**. Timeframe prompt shows examples `30s / 5m / 1h` inline; tags prompt reads `tags (optional · comma-separated)` with example `e.g. meeting, pricing`. Empty tags input yields an empty list.
- **AC-2** REC header reads `● REC · mm:ss / MM:SS · mic: <device-name>` where `mm:ss` is elapsed and `MM:SS` is the timeframe cap (if set) or blank. The leading red `●` dot matches A3.
- **AC-3** Control hints at the bottom of the live dashboard read:
  ```
  [space] pause   [q / ^C] stop & save   [x] discard
  ```
- **AC-4** The waveform box in A3 renders and updates in real time — block-glyphs (`▁▂▄▅▇█`) scale to current input amplitude. Box chrome: `╭────── waveform ──────╮` border. Redraws at ~10 Hz, driven by the existing audio stream callback (no new capture path).
- **AC-5** A single-line `⠋ listening...` status renders below the waveform and above the controls, using `rich.spinner.Spinner("dots")`. When paused, the line flips to `⏸ paused`; when the timeframe cap is reached, it flips to `■ stopped`.
- **AC-6** Audio is written to `notes_root/<slug>/audio.wav` (from story 1.1), not `settings.directories.raw_audio/…`. The slug is computed from title + today's date via `slugify`. Tags captured in AC-1 are written to `meta.toml` as `tags = [...]` at record start.
- **AC-7** On stop-and-save, the final console line reads:
  ```
  ✅ saved to ~/Documents/chirp/<slug>/
  › chirp transcribe    · turn this into notes
  ```
- **AC-8** On discard (`x`), the entire `<slug>/` folder is `shutil.rmtree`'d (no orphan `meta.toml`), and the console prints `discarded.`
- **AC-9** Pause does not close the audio file — pressing space again resumes into the same `audio.wav`. (Current behavior — confirm not regressed.)
- **AC-10** The live transcript preview under the controls keeps streaming via `on_segment` — this is the **only** place streaming previews are rendered (transcribe no longer streams, per story 1.4).
- **AC-11** `uv run pytest` passes; any record-related test that asserted the old path layout is updated. Add a test for the tags prompt parsing (empty / `"meeting"` / `"a, b"` / `"  a ,b , c "` → `[]` / `["meeting"]` / `["a","b"]` / `["a","b","c"]`).

## Implementation tasks

1. **Add tags prompt** — in `chirp/cli.py:211` add a `_prompt_tags()` helper after `_prompt_timeframe()`. Parse comma-separated input, strip whitespace, drop empties. Return `list[str]`.
2. **Audit prompts** — confirm order and copy in `chirp/cli.py:211`. Adjust timeframe prompt to show `(e.g. 30s / 5m / 1h)` if not already present.
3. **Rewrite header** — current `live_dashboard.py:239` reads `" LIVE TRANSCRIPTION • {elapsed_text} "`. Replace with the `● REC · mm:ss / MM:SS · mic: <device>` format in AC-2.
4. **Waveform** — update the current waveform render to scale per-frame from the audio callback's RMS/peak. If no waveform exists yet, add one using the amplitude already available to the live dashboard. Use the A3 chrome `╭────── waveform ──────╮`.
5. **Listening spinner** — update the existing listening indicator to the `⠋ listening...` / `⏸ paused` / `■ stopped` states in AC-5.
6. **Audit control hints** — confirm the hint line matches AC-3 exactly (spacing, order).
7. **Plumb save path** — if story 1.1 already repointed `audio_recorder` at `notes_root/<slug>/audio.wav`, this is a no-op. Otherwise, update here. Persist tags into the initial `meta.toml` write.
8. **Discard path cleanup** — ensure `x` triggers full folder removal; add the removal in whichever handler owns discard.
9. **Post-save hint** — update the console output after a successful save to the AC-7 copy.
10. **Tests** — snapshot-test the rendered header, waveform chrome, spinner, and hint strings; integration test that `x` leaves no `<slug>/` folder behind; unit test for `_prompt_tags` parsing.
