# Story 1.1 — Storage rewrite: one folder per note, TOML config

- **Status:** Done
- **Epic:** [EPIC-WF-ALIGN](../epic.md)
- **Depends on:** —
- **Blocks:** 1.2, 1.3, 1.4, 1.5, 1.6, 1.7

## User story

As a Chirp user, I want every recording, transcript, note, and metadata file for one meeting kept together in a single folder — named after the meeting — so that browsing, sharing, or deleting a meeting's artifacts is a single filesystem operation and the layout matches the wireframe's locked decision 5.

## Context

The wireframe locks the on-disk layout. The current implementation splits by kind (`recordings/`, `transcripts/`, `notes/`) and compresses transcripts to `.json.gz` with a sibling `metadata.json`. Everything downstream (scanners in `utils/file_utils.py`, the indexer in `notes_chat/index.py`, CLI output in `chirp/cli.py`) assumes the old shape. This story changes the shape at the source and ripples the change through each consumer.

**New layout:**

```
~/Documents/chirp/
  <slug-YYYY-MM-DD>/
    audio.wav
    transcript.txt        # plain text (replaces per-recording *.json.gz)
    notes.md
    meta.toml             # title, date, duration_s, tags, whisper_model, llm_model, indexed_at

~/.chirp/
  config.toml             # moved from user_config_dir/config.yaml
  chroma/                 # vector store, unchanged semantics, new location
```

No back-compat. Old paths are removed outright.

## Acceptance criteria

- **AC-1** `ChirpSettings.directories` exposes a single `notes_root: Path` (default `~/Documents/chirp`) and drops `raw_audio`, `transcriptions`, `notes`, `templates`.
- **AC-2** Config file path is `~/.chirp/config.toml`. Reading uses `tomllib`, writing uses `tomli-w` (new dependency, added to `pyproject.toml`).
- **AC-3** `~/.chirp/chroma/` is the vector-store location; `notes_chat.index_dir` resolves there.
- **AC-4** A `NoteRecord` dataclass (or `TypedDict`) is introduced in `utils/file_utils.py` with fields `slug: str`, `dir: Path`, `audio: Path | None`, `transcript: Path | None`, `notes: Path | None`, `meta: Path | None`, `created_at: datetime`, `tags: list[str]` (from `meta.toml`, default `[]`).
- **AC-5** `utils/file_utils.list_notes(notes_root) -> list[NoteRecord]` scans `notes_root/*/` and returns records sorted by `created_at` ascending (FIFO).
- **AC-6** A `slugify(title: str, date: date) -> str` helper returns kebab-case `<title>-YYYY-MM-DD`; on collision it appends `-2`, `-3`, etc.
- **AC-7** `recorder/audio_recorder.py` writes audio to `notes_root/<slug>/audio.wav` and writes an initial `meta.toml` with `title`, `date`, `mic`, `tags` at record time.
- **AC-8** `transcriber/batch_processor.py` writes plain `transcript.txt` (no compression, no sibling `metadata.json`) into the same `<slug>/` folder.
- **AC-9** `notes/note_generator.py` writes `notes.md` into the same folder and updates `meta.toml` with `whisper_model`, `llm_model`, `indexed_at`.
- **AC-10** `notes_chat/index.py` scans `notes_root/*/notes.md`; manifest is keyed by absolute `notes.md` path.
- **AC-11** `chirp/init_flow.py` Phase 4 writes `~/.chirp/config.toml`, creates `~/.chirp/chroma/`, ensures `~/Documents/chirp/` exists.
- **AC-12** Root directory is lowercase `chirp`, not `Chirp`.
- **AC-13** `uv run pytest` passes; the full compression path (`transcriber/compression.py`) is either removed or untouched but unused.
- **AC-14** `uv run ruff check .` reports no issues.

## Implementation tasks

1. **`config/settings.py`**
   - Replace `DirectoriesConfig` with a `notes_root: Path` field defaulting to `Path(user_documents_dir()) / "chirp"`.
   - Drop `templates`, `raw_audio`, `transcriptions`, `notes` fields and their `create_default_config` lines.
   - Change `get_config_path` to return `Path.home() / ".chirp" / "config.toml"`.
   - Replace `yaml.safe_load` with `tomllib.loads`; replace `yaml.dump` with `tomli_w.dumps`.
   - Update `ensure_directories_exist` to create `notes_root`, `~/.chirp/chroma/`, `~/.chirp/`.
   - Remove template-engine bootstrap (templates live in-repo now; confirm current callers).
2. **`utils/file_utils.py`**
   - Add `NoteRecord` dataclass.
   - Add `list_notes(notes_root: Path) -> list[NoteRecord]`.
   - Add `slugify(title: str, date: date) -> str` with collision handling (inspect existing slugs in `notes_root`).
   - Remove `get_audio_files`, `get_transcription_files`, `get_notes_files` (or make them `list_notes` wrappers until the last caller is gone, then delete).
3. **`recorder/`**
   - At record start, prompt title, compute slug, create `notes_root/<slug>/`, start writing `audio.wav` into it.
   - Write `meta.toml` with `title`, `date`, `mic`, `duration_s` (updated on stop) using `tomli_w`.
4. **`transcriber/batch_processor.py`**
   - Iterate `list_notes(notes_root)`; filter to records where `transcript is None` or empty, unless `force=True`.
   - Write plain UTF-8 `transcript.txt` beside `audio.wav`.
   - Delete `_get_output_path`, `_write_metadata_file`, and `.json.gz` paths.
   - Drop `JSONCompressor` usage (keep module for now, remove in a follow-up if unused).
5. **`notes/note_generator.py`**
   - Write `notes.md` next to the audio/transcript.
   - After write, read existing `meta.toml`, merge in `whisper_model`, `llm_model`, `indexed_at` (ISO 8601), write back.
6. **`notes_chat/index.py`**
   - Replace any scan over `settings.directories.notes` with a scan of `notes_root/*/notes.md`.
   - Manifest keys stay as absolute paths.
7. **`chirp/init_flow.py`**
   - Phase 4: write `~/.chirp/config.toml`, create `~/.chirp/chroma/`, confirm `~/Documents/chirp/` exists.
8. **`chirp/cli.py`**
   - Replace every reference to `settings.directories.raw_audio|transcriptions|notes|templates` with `settings.directories.notes_root` + `list_notes(...)`.
   - Leave command structure alone — that is story 1.2.
9. **`pyproject.toml`**
   - Add `tomli-w` to dependencies. `tomllib` is stdlib (Python 3.11+).
10. **Tests**
    - Update any fixture that seeds `recordings/`, `transcripts/`, `notes/` to instead seed `notes_root/<slug>/…`.
    - Add a unit test for `slugify` collision handling (`standup-2026-04-20`, `standup-2026-04-20-2`).
    - Add a unit test for `list_notes` returning FIFO order.

## Dev notes

- `tomllib` is stdlib since Python 3.11 — project is already 3.11+.
- `tomli-w` is the de-facto writer for the stdlib-reader pair; ~500 lines, zero runtime deps.
- The `.coverage` file in the repo root comes from an older test run — no action, but don't be surprised if coverage diffs look large after this story.
- `transcriber/compression.py` (`JSONCompressor`) may have no consumers after this story. Search for `JSONCompressor` imports after the rewrite; delete the module if orphaned.
- `notes/template_engine.py` is currently invoked from `settings.ensure_directories_exist` to seed templates. Confirm whether templates are still needed in the new layout before wiring that call back in — if templates are only for `setup`/`test` (commands slated for deletion in story 1.2), the engine can be removed.
