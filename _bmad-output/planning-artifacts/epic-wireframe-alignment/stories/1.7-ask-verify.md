## User story

As a Chirp user opening an interactive chat over my notes, I want the banner, exit hint, and sources format to read exactly as the wireframe A5 specifies, so that the interactive experience feels polished and the conventions (how sources are shown) are stable enough to document.

## Context

`ask` already supports interactive and one-shot modes, `--markdown/--no-markdown` (default on), `--sources`, `--when`, and `--dry-run` (cli.py:556). This story is a polish pass on three pieces of copy.

## Acceptance criteria

- **AC-1** Interactive session banner reads:
  ```
  Chirp · chat over <N> notes · <model> (local)
  ```
  where `<N>` is `len(list_notes(notes_root))` and `<model>` is `settings.models.llm`.
- **AC-2** Under the banner, the exit hint reads:
  ```
  type your question, or /help · ctrl+d to exit
  ```
- **AC-3** Source citations at the end of an answer are formatted as:
  ```
  sources: note #2 (12:40), note #4
  ```
  where `#N` matches the same index `chirp notes` list prints, and the optional `(mm:ss)` timestamp shows only when the retrieved chunk has a timestamp in its metadata. Otherwise just `#N`.
- **AC-4** `--markdown` default stays `True`; Markdown rendering uses `rich.markdown.Markdown`.
- **AC-5** `--no-markdown` yields plain text output suitable for piping.
- **AC-6** `--sources/--no-sources` toggles the sources footer.
- **AC-7** `--dry-run` prints the prompt that would be sent and exits without calling Ollama.
- **AC-8** `uv run pytest` covers: banner format with N substituted, source-line format with and without timestamps, markdown vs. plain toggle.

## Implementation tasks

1. **Locate banner** in `notes_chat/cli.py` (or wherever the interactive session header is printed) and update text to AC-1.
2. **Locate exit hint** under the banner; update to AC-2.
3. **Update sources formatter** in `notes_chat/retrieval.py` or `prompting.py` — wherever the `sources: …` line is assembled. The note `#N` must come from the same index `chirp notes` uses (reversed `list_notes` — 1-based, newest first).
4. **Expose timestamp** — if chunks carry a `start_ms` (or similar) in their Chroma metadata, format `(mm:ss)` from it. Otherwise omit.
5. **Tests** — stub retrieval to return a fixed set of chunks with / without timestamps; assert the `sources:` line formats correctly.

## Dev notes

- Keep `--when` behavior and all other options unchanged.
- `list_notes` is FIFO (oldest-first); the table shows `reversed(list_notes(...))` (newest-first). The `#N` index must match the table's reversed order — this is the same invariant from story 1.3.
- If chunks from the same note are cited multiple times, collapse to one `#N` entry with the earliest timestamp.

## Testing

- Manual: seed 5 notes, run `chirp ask` interactive, verify banner shows `chat over 5 notes`, exit hint matches, type a question, verify sources line.
- Manual: `chirp ask --no-markdown -q "what did we decide?"` pipes clean.
- Unit: sources-formatter tests.
